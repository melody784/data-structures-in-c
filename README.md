# 数据结构 C 语言实现

本仓库存放大一暑假期间学习《数据结构》时手写的核心代码。  
目前已从“单文件验证”升级为“多文件工程结构”，并开始引入边界测试与 Git 分支管理。

---

## 工程结构

```text
.
├── seqlist.h          # 顺序表头文件（结构体定义、函数声明、头文件卫士）
├── seqlist.c          # 顺序表函数实现（增删改查、边界判断）
├── main.c             # 测试入口（包含功能测试与边界异常测试）
├── linklist.c         # 单链表实现（待重构为多文件结构）
└── README.md          # 本文件
```


## 编译与运行（多文件工程）

> 注意：本项目已不再使用 F5 一键运行，请手动执行以下命令。

```bash
# 编译顺序表测试程序（必须同时包含两个 .c 文件）
gcc main.c seqlist.c -o test_seqlist

# 运行测试
.\test_seqlist.exe
```

## 测试覆盖说明

main.c 中不仅包含正常功能测试（插入、删除、查找），还包含以下边界测试：

```text
向已满的顺序表插入元素 → 预期返回错误码
在非法位置（-1 或超出长度）操作 → 预期拒绝执行
对空表执行删除或取值操作 → 预期返回错误码
```

这些测试是为了防御性编程，确保程序在极端输入下不会崩溃。
