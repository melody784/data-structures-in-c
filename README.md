# 数据结构 C 语言实现

本仓库存放大一暑假期间学习数据结构时，用 C 语言手写的核心代码。

## 📁 文件说明
| 文件名 | 对应章节 | 功能描述 |
| :--- | :--- | :--- |
| `linklist.c` | 第二章 线性表 | 单链表的创建、插入、删除、查找 |
| `sqlist.c` | 第二章 线性表 | 顺序表的实现 |

## 🛠 编译与运行
- **编译器**：MinGW (gcc)
- **编译命令**：`gcc 文件名.c -o 文件名.exe`
- **运行示例**：`.\linklist.exe`
